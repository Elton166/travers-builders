TRAVERS BUILDERS WEBSITE
========================

What is in this folder
  index.html         the main website (one page)
  images/            the photos used on the main page
  about/index.html   the About page (Travers, the founder)
  about/travers.jpg  the founder photo

To look at it on your computer
  Double-click index.html. It opens in your browser.
  The About link in the menu opens the About page.
  The fonts load from Google Fonts, so connect to the internet to see the final look.

To put it online
  Upload everything in this folder to your web hosting, into the main folder for
  www.traversbuilders.co.za (often called public_html). Keep the folders next to index.html.

To change things later
  Open index.html or about/index.html in a text editor (Notepad works).
  Phone number: search for 061 788 9142 and 27617889142 (the second one is the WhatsApp link).
  Email: search for admin@traversbuilders.co.za
  Photos: replace the files in the images folder or about folder, keeping the same file names.

The quote form opens WhatsApp with the message already written. It does not send email by itself.
